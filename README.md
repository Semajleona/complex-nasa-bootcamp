## 📖 Description

A web application that displays NASA facility locations and their current temperatures. The app uses the NASA Facilities API to retrieve facility information and WeatherAPI to display real-time weather data based on each facility's coordinates.

## ✨ Project Features

- Displays NASA facility names and locations.
- Fetches facility data from the NASA Facilities API.
- Uses latitude and longitude to retrieve current weather information.
- Displays temperatures in Fahrenheit.
- Dynamically updates the webpage when users click the "Show All Locations" button.

## 🛠️ Tech Stack

- **HTML5** — Structures the webpage.
- **CSS3** — Styles the layout and design.
- **JavaScript** — Handles user interactions and displays API data.
- **Node.js & Express.js** — Handles backend requests to external APIs.
- **NASA Facilities API** — Provides NASA facility information and coordinates.
- **WeatherAPI** — Provides current temperature data.

## 🧠 What I Learned

- How to fetch and display data from external APIs.
- How to use data from one API to make requests to another API.
- How to loop through arrays of objects and access specific properties.
- How to dynamically update HTML elements using JavaScript.
- How to use Node.js and Express.js to handle API requests and work around CORS restrictions.

## 💻 How to Install

1. Clone the repository:
   ```bash
   git clone https://github.com/Semajleona/complex-nasa-bootcamp.git
   ```
2. Navigate to the project folder:
   ```bash
   cd complex-nasa-bootcamp
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Configure any required API keys or environment variables.
5. Start the application:
   ```bash
   npm start
   ```
6. Open the local address displayed in your terminal in a web browser.
